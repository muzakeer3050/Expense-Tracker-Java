# Expense Tracker

A console-based Expense Tracker application developed using Core Java.

This project allows users to manage their daily expenses through a simple menu-driven interface.

## Features

- Add new expenses
- View all recorded expenses
- Delete expenses using their ID
- Calculate total expenses
- View category-wise expense summaries
- Save and load expenses using file handling

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- File Handling
- Exception Handling

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Follow the menu displayed in the console.
